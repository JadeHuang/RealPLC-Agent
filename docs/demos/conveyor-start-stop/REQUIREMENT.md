# 输送线启停需求

本目录是 **输送线启停** 在 RealPLC Agent v1.1.4 + CODESYS 上的演示契约。官网画面、旧模板或其他示例若与下文不一致，以本目录为准。

演示步骤见 [RUNBOOK.md](RUNBOOK.md)。

## 场景

一条输送线由启动、停止、急停、过载、运行反馈、故障复位和物料检测共同决定电机是否允许运行。

- 操作员按启动后，在联锁满足时发出运行命令。
- 停止或急停立即撤销运行命令。
- 过载，或发出运行命令后运行反馈超时，锁存故障。
- 故障条件消失后，必须由人工复位清除锁存。
- 复位只清除故障，不得把电机再次启动。

样例程序是 `FB_Conveyor`。现场电机 **M1** 对应输出 `MotorRun`，物料检测 **S01** 对应输入 `S01_PartDetect`。

## 统一 I/O

下表是唯一现场 I/O 契约。类型均为 `BOOL`。

| 方向 | 名称 | 设备 | 含义 |
| --- | --- | --- | --- |
| 输入 | `StartPb` | 启动按钮 | 上升沿尝试发出运行命令 |
| 输入 | `StopPb` | 停止按钮 | 为 TRUE 时立即撤销运行命令 |
| 输入 | `EStopOk` | 急停回路 | TRUE 表示回路正常；FALSE 表示急停，立即撤销运行命令 |
| 输入 | `OverloadTrip` | 过载 | 为 TRUE 时锁存故障并撤销运行命令 |
| 输入 | `RunningFb` | 运行反馈 | 电机实际运行反馈。发出运行命令后长时间为 FALSE，按反馈超时处理 |
| 输入 | `ResetPb` | 复位按钮 | 上升沿清除已锁存故障；不发出运行命令 |
| 输入 | `S01_PartDetect` | S01 | 物料检测。作为启动运行许可：为 TRUE 才接受启动沿 |
| 输出 | `MotorRun` | M1 | 电机运行命令 |
| 输出 | `FaultLatched` | — | 故障锁存。TRUE 表示须人工复位后才允许再次启动 |

`S01_PartDetect` 参与运行许可，不悬空：无物料时启动沿被拒绝。输送线已经运行后，S01 变为 FALSE 不单独停机，也不单独锁存故障；停机与锁存仍由停止、急停、过载和反馈超时负责。

反馈超时使用 `TON`，初值 `T#3S`（3 秒）。时间放在功能块内部变量 `FbTimeout`，修改该初值即可配置，它不是现场 I/O，也不增加上表以外的契约信号。

## 联锁

同一扫描周期内按以下顺序处理：

1. 用 `R_TRIG` 取 `StartPb`、`StopPb`、`ResetPb` 的上升沿。
2. 启动沿仅在下列条件全部成立时置位内部运行记忆：急停正常、停止未按下、无过载、故障未锁存、S01 检测到物料。
3. 停止按钮的上升沿，以及停止、急停的电平，立即清除运行记忆。松开停止或恢复急停不会按旧记忆再启动。
4. 运行记忆为 TRUE 且 `RunningFb` 为 FALSE 时，`TON` 累计；达到 `FbTimeout` 则超时。
5. 过载或反馈超时置位 `FaultLatched`，并清除运行记忆，避免复位后沿用旧命令。
6. 过载已消失、反馈超时条件已撤销且急停正常时，复位上升沿只清除 `FaultLatched`。
7. `MotorRun` 由运行记忆与急停、停止、过载、故障锁存相与得到。复位不置位运行记忆，因此不会自动重启电机。

`EStopOk` 为 FALSE、过载仍在，或反馈超时仍成立时，复位沿无效。

## 验收

| # | 准则 | 通过判定 |
| --- | --- | --- |
| 1 | 停止或急停立即撤销运行命令 | `StopPb` 变为 TRUE，或 `EStopOk` 变为 FALSE 的同一扫描周期内，`MotorRun` 为 FALSE。松开停止或恢复急停后，`MotorRun` 仍为 FALSE |
| 2 | 过载或反馈超时触发故障锁存 | `OverloadTrip` 为 TRUE，或运行命令发出后 `RunningFb` 在 `FbTimeout` 内仍为 FALSE 时，`FaultLatched` 变为 TRUE，且 `MotorRun` 为 FALSE |
| 3 | 故障清除后需人工复位 | 过载消失或超时条件撤销后，`FaultLatched` 保持 TRUE，直到 `ResetPb` 出现一次新的上升沿 |
| 4 | 复位不得自动重启电机 | 复位沿之后，在没有新的 `StartPb` 上升沿之前，`MotorRun` 保持 FALSE。复位当时即使启动按钮仍按住，也不得启动 |

IDE Simulation 的操作顺序见 RUNBOOK 的检查清单。
